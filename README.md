# Doctor Appointment Booking
A clinic management console where a receptionist books doctor appointments for patients. MySQL stores everything. A separate HTML+JS dashboard shows today's appointments visually.

## Authors
- [@ChaitanyaKhajone](https://www.github.com/ChaitanyaKhajone)
- [@tanishq0264](https://www.github.com/tanishq0264)

## Features
#### Patient Management
- Register new patients
- Store patient details in MySQL
- Search patients by name

#### Doctor Management
- Maintain doctor records
- Store doctor specialization
- Consultation fee management

#### Appointment Management
- Book appointments
- Cancel appointments
- View today's appointments 
- Prevent double-booking of doctor slots
- Slot availability validation

#### Dashboard
- View today's appointments
- Filter appointments by doctor
- Filter appointments by status
- Dynamic data loading using Fetch API and JSON

## Tech Stack
**Backend:** JAVA, JDBC, MySQL.
**Frontend:** HTML5, CSS, JavaScript, Fetch Api.
